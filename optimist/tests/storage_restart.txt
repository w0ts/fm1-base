# The trial in the host simulator (milestone 3): a power-on in a new process with the flash tests/storage.txt left
# (OPT_FLASH=optimist/build/host/trial-flash.bin: loaded before anything reads it), or the one Optimist's own simulator
# wrote doing the same (optimist-flash.bin: optsim.py write, its firmware on a blank flash). Everything saved is found again
# through the UI: the work as it was left (the autosave: BPM 116, DEC 116), the setting (KNOB COLORS ON, from the settings
# record at 0xFC000), project slot 3 loaded over a NEW project, U01 loaded over a changed sound. Then a second autosave
# (the copy that is not the current one: B, 0xFE000, outside plat.h's windows) with BPM 120, and the flash dumped again
# (OPT_DUMP) for tests/storage_resume.txt. optimist/run.sh runs it:
#   OPT_FLASH=optimist/build/host/trial-flash.bin OPT_DUMP=optimist/build/host/trial-flash2.bin optimist/build/host/optimist_host optimist/tests/storage_restart.txt optimist/build/host
