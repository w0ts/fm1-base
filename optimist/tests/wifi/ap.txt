# Optimist's MODE AP in the trial on fm1-base's own Wi-Fi stack (device/wifi_own_ap.c), in the host simulator with
# the simulator's client of the FM-1's access point as a phone (host/wifi_air_client.c; OPT_HOST_BT=1 OPT_HOST_WIFI=1
# with profiles/dev-wifi.config: optimist/run.sh's wifi-ap run; ui/opt_wifi.h). SYSTEM > WI-FI: MODE AP AUTO with no
# typed key: the access point comes up by itself under its automatic name with the default password, a function of the
# name (wifi_ap_default_key: nothing kept); the phone joins with it; a restart keeps it; a typed password (as the page's
# entry or the web editor's op 5 give it: plat_wifi_ap_set) replaces it; CLEAR KEY gives the default one back. The phone joins, gets 192.168.4.2 and is a Link peer: STATE alternates the clients
# and the Link peers; the session's start followed as the clock; CHANNEL turned on the page (the access point moves,
# the phone joins again); a restart (AP AUTO kept: up again); AP MAN (off, SAVE starts it); CLEAR KEY
wait 1500
master 2048
wait 100
tap GLO
wait 100
tap GLO
wait 100

cells
